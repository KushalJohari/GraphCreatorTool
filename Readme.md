# 📊 Graph Creator Tool

A simple and interactive web application built with **Streamlit** that allows users to upload CSV files and generate various types of graphs using **Pandas**, **Matplotlib**, and **Seaborn**.

---

## 🚀 Features

- 📁 Upload CSV files directly through the interface.
- 📈 Choose from multiple graph types:
  - Bar Graph
  - Line Plot
  - Pie Chart
  - Histogram
- ⚙️ Aggregation options:
  - Count
  - Mean
  - Sum
  - Value Counts
- 🎨 Custom color picker for graph styling.
- 📥 Download the generated graph as a PNG image.

---

## 🖥️ Tech Stack

- [Streamlit](https://streamlit.io/)
- [Pandas](https://pandas.pydata.org/)
- [Matplotlib](https://matplotlib.org/)
- [Seaborn](https://seaborn.pydata.org/)
